# Aktivni Zaedno

"Active Together": a Bulgarian platform for mass sport and sports communities. Find sports partners,
organize activities, build sports communities. Any sport, any age, any city.

## Workspaces
- `az-web`: Next.js web app and REST API
- `az-mobile`: Expo mobile app (coming later)
- `az-shared`: shared types and constants

## Getting started
```bash
npm install
npm run dev   # http://localhost:3000 -> redirects to /bg
```

See `AGENTS.md` for project conventions and `docs/` for the full concept.
